# 🏃‍♂️ FunRun Rush 3D

A 3D endless runner game built using **Three.js**, JavaScript, HTML, and CSS. The player runs through a jungle-themed environment, avoids obstacles, collects rewards, and tries to achieve the highest score.

---

## 🎮 Features

* 3D gameplay powered by Three.js
* Smooth lane switching
* Jump and slide mechanics
* Multiple obstacle types

  * Fire
  * Rolling Logs
  * Spikes
  * Low Branches
* Character selection system
* Settings menu
* Pause, Resume, Restart, and Home navigation
* Near Miss bonus system
* Combo score system
* Dynamic camera movement
* Sound effects and ambient audio
* Jungle environment with lighting and fog effects

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## 🚀 How to Run

### 1. Open Terminal

Navigate to the project folder:

```bash
cd C:\Users\HP\voice-game-3d
```

### 2. Start Local Server

```bash
npx serve www -l 5001
```

### 3. Open in Browser

```text
http://localhost:5001
```
